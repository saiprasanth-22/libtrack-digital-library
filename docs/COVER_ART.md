# Cover-art pipeline

LibTrack's catalogue artwork is **original, deterministic, and text-free**.
Nothing is scraped, traced, or derived from publisher covers.

## How it works

1. Every book resolves to one of **16 subject families** via
   `Book.cover_family` (explicit) or its first category (fallback), defined in
   `core/cover_art.py`.
2. A SHA-256 hash of the slug deterministically picks a **palette** (6
   print-tuned colour sets: forest, ink, oxide, parchment, teal, slate), a
   **motif variant** (3 per family) and a **rotation**, so adjacent books are
   never visibly identical while the system stays coherent.
3. The `generate_covers` command renders one text-free **SVG** per book under
   `static/images/covers/<family>/<slug>.svg` (1200×1800, 2:3) and writes
   `static/images/covers/manifest.json`.

```bash
python manage.py generate_covers           # generate missing artwork
python manage.py generate_covers --force   # regenerate everything
python manage.py generate_covers --family algorithms
```

4. Templates render the artwork through the manifest
   (`Book.generated_cover_file`) with `object-fit: cover`, and apply **all
   readable typography (title, author, edition) in HTML/CSS**. A generated
   asset can therefore never contain misspelled or AI-mangled title text.

## Manifest

`static/images/covers/manifest.json` records, per book slug: artwork file,
subject family, palette, motif variant, alt text and a provenance note. It is
regenerated by the command and read (cached) by the application.

## Image provenance policy

- All artwork is generated at build time by LibTrack's own deterministic
  code. No third-party image, font raster, publisher cover, or scraped file
  is used at any point.
- Motifs are abstract: grids, node networks, relational rows, system layers,
  statistical curves, dependency plans, lattices. They reference *subject
  matter*, never artists, characters, or logos.
- Colours reuse the existing product palette (deep forest, parchment, ink,
  oxide brown, muted teal, aged gold) so covers look like they have always
  belonged to LibTrack.
- Alt text describes the artwork (the title sits adjacent in the markup).

## Asset size

The full set of 128 SVG covers is ~0.7 MB total (roughly 3–6 KB each) —
smaller than a single typical JPEG thumbnail, resolution-independent at every
viewport, and sharp under the product's 3D `rotateY` transforms.

## Upgrading to raster artwork later

If individually art-directed raster covers are wanted later (e.g. for the
featured shelf), generate them from these ready-to-use prompts, then extend
`build_svg`'s call sites or the manifest. The spec for each:

> 2:3 portrait, 1200×1800+, sRGB, flat editorial illustration, tactile paper
> grain, palette limited to deep forest green #173c34, parchment #f7f0e3,
> ink #1d2833, oxide brown #6b4a34, muted teal #49cfa3, aged gold #c8a35f;
> controlled contrast, generous negative space in the upper third reserved
> for title typography, no text, no logos, no letters, no publisher marks,
> no characters, no glossy AI glow, no photographic depth-of-field blur.

Per-family prompts (append to the spec above):

| family | prompt continuation |
|---|---|
| programming | "modular grid of small rectangles and punched-card columns, quiet rhythm of repeated geometric marks" |
| algorithms | "abstract node-and-edge network forming a tree, layered graph topology" |
| databases | "stacked horizontal record rows with small circular index markers, relational archive geometry" |
| operating-systems | "four to five offset stacked layers receding in space, process-block diagram" |
| networking | "scattered points connected by thin lines, routing paths crossing a muted field" |
| web | "rectangular modular frames in a responsive grid, browser-like window proportions without chrome" |
| artificial-intelligence | "layered inference graph with decision-boundary arcs, symbolic and neural motifs combined" |
| data-science | "two sine-like statistical curves with plotted dot marks, distribution shapes" |
| software-engineering | "orthogonal architectural plan: nested outlined rectangles with a single accent rule, dependency diagram" |
| cybersecurity | "even lattice of squares with a few filled cells inside a strong boundary frame, keyhole-free" |
| cloud | "horizontal service layers connected by short vertical links, abstract infrastructure topology, no cartoon cloud" |
| business | "elegant bar-like rectangles and thin rule lines, dashboard abstracted into editorial geometry" |
| mobile | "tall rounded rectangle proportioned like a device-independent touch grid, interface layer rows" |
| marketing | "converging pathway lines meeting small audience dots, publication network" |
| mathematics | "coordinate field with a clean geometric construction: circle, chords, tangent curve" |
| employability | "ascending milestone markers along a path, planning artefacts, collaborative node cluster" |

Any raster file placed at `static/images/covers/<family>/<slug>.webp` and
registered in the manifest with the same provenance fields replaces the SVG
for that book without template changes.
