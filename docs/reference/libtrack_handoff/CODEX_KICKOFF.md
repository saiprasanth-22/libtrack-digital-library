## First implementation task
Do **only Phase 1 + Phase 2** first:
1. establish tokens/global styles
2. create reusable typography, navbar, button, search, chip, badge, and card primitives
3. implement the landing/hero at production quality
4. implement responsive behavior
5. implement the **Watch Platform Tour** interaction shell
6. do not build the remaining screens yet

## Technical direction
- Next.js + TypeScript
- Tailwind CSS or CSS Modules
- Framer Motion for restrained motion
- Lucide for icons
- use local mock data first

## Visual constraints
- cream / forest green / warm brown / ink identity
- Instrument Serif + Manrope or closest available equivalents
- emerald is functional, not decorative
- preserve premium editorial hierarchy
- avoid generic dashboards
- no stock photos of students
- no purple/blue AI gradients
- no excessive glassmorphism

Before coding, summarize:
- component tree
- token strategy
- responsive plan
- what will be built in CSS/components versus image assets

Then implement.
